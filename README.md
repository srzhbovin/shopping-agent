# Агент для проверяемой товарной корзины

Проект принимает бытовую задачу пользователя и превращает её в корзину из товаров каталога. На первом этапе готова основа данных и поиска. Здесь нет товаров, придуманных языковой моделью. Каждая позиция имеет идентификатор каталога, цену, характеристики и отзывы.

## Что уже работает

Приложение хранит товары и отзывы в SQLite. Оно выполняет поиск по словам через BM25 и поиск по смыслу через Qdrant. Векторы для поиска создаёт локальная модель из LM Studio. Два результата объединяются и повторно сортируются.

Доступны инструменты поиска, чтения карточки, сводки отзывов, сравнения, расчёта бюджета и изменения корзины. Денежные расчёты выполняются обычным кодом с Decimal.

Небольшой демонстрационный каталог лежит в проекте. Он позволяет проверить весь этап без скачивания многогигабайтных файлов Amazon. Все его идентификаторы начинаются с `DEMO`. Для настоящих данных предусмотрен отдельный загрузчик.

## Быстрый запуск через Docker

Нужны Docker Desktop и запущенный локальный сервер LM Studio. В LM Studio должна быть загружена модель `text-embedding-nomic-embed-text-v1.5`, а сервер должен слушать порт 1234.

Для агентных ролей используется `qwen/qwen3.5-4b`. Модель можно скачать и загрузить командами ниже.

```bash
lms get qwen/qwen3.5-4b --gguf -y
lms load qwen/qwen3.5-4b --context-length 8192 --parallel 1 --yes
```

Модель эмбеддингов `Nomic Embed Text v1.5` нужно скачать через раздел поиска LM Studio и загрузить перед запуском.

```bash
docker compose up --build -d
docker compose ps
docker compose exec api /app/.venv/bin/shopping-agent check-models
curl http://localhost:8010/health
curl -X POST http://localhost:8010/demo/verify
```

Команда `check-models` проверяет и Qwen, и модель эмбеддингов настоящими запросами. Последняя команда выполняет настоящий поиск, получает отзывы, собирает корзину и проверяет бюджет.

Если порт 8010 занят, перед запуском задайте другой через переменную `API_PORT`.

Остановить сервисы можно так.

```bash
docker compose down
```

## Запуск без Docker

Qdrant всё равно должен быть доступен на порту 6333.

```bash
python -m venv .venv
python -m pip install uv==0.12.10
python -m uv sync --frozen --extra dev
python -m uv run uvicorn shopping_agent.api:app --reload
```

Для проверки тестов выполните команду.

```bash
python -m uv run --extra dev pytest
python -m uv run --extra dev ruff check src tests scripts
```

## Настоящие данные Amazon

Файлы Amazon Reviews 2023 очень большие. Метаданные Home and Kitchen занимают около 3 ГБ в сжатом виде, а отзывы около 8 ГБ. Поэтому они не загружаются при обычном запуске.

Загрузчик читает локальные файлы `jsonl` или `jsonl.gz` потоково и может остановиться после заданного числа записей.

```bash
python scripts/import_amazon_reviews.py \
  --metadata data/raw/meta_Home_and_Kitchen.jsonl.gz \
  --reviews data/raw/Home_and_Kitchen.jsonl.gz \
  --limit-products 10000 \
  --limit-reviews 50000
```

После загрузки перезапустите приложение. Индекс обновится автоматически.

## Состав первого этапа

Первый этап считается готовым, когда проходят модульные тесты, Qdrant отвечает, LM Studio создаёт векторы, демонстрационная проверка возвращает товары из каталога и итоговая сумма совпадает с суммой позиций.

На втором этапе появятся планировщик, исследователь и критик. На третьем этапе появятся измерения на ESCI, сравнение вариантов поиска, проверки полных сценариев и простой пользовательский интерфейс.
