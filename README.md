# Агент для проверяемой товарной корзины

Проект принимает бытовую задачу пользователя и превращает её в корзину из товаров каталога. Готовы основа данных, поиск и агентный граф. Здесь нет товаров, придуманных языковой моделью. Каждая позиция имеет идентификатор каталога, цену, характеристики и отзывы.

## Что уже работает

Приложение хранит товары и отзывы в SQLite. Оно выполняет поиск по словам через BM25 и поиск по смыслу через Qdrant. Векторы для поиска создаёт локальная модель из LM Studio. Два результата объединяются и повторно сортируются.

Доступны инструменты поиска, чтения карточки, сводки отзывов, сравнения, расчёта бюджета и изменения корзины. Денежные расчёты выполняются обычным кодом с Decimal.

Планировщик на локальной Qwen выделяет бюджет, запреты, предпочтения и поисковые задачи. Исследователь вызывает инструменты каталога для каждой задачи. Критик повторно проверяет товары и бюджет и может вернуть корзину на исправление не более двух раз.

Состояние сессии хранится отдельно от истории сообщений. Поэтому просьба заменить один товар меняет существующую корзину без полной пересборки. Расход токенов накапливается в состоянии сессии. После исчерпания лимита или при недоступности Qwen используется ограниченный разбор правилами, а причина сохраняется в показателях запуска.

Небольшой демонстрационный каталог лежит в проекте. Он позволяет проверить весь этап без скачивания многогигабайтных файлов Amazon. Все его идентификаторы начинаются с `DEMO`. Для настоящих данных предусмотрен отдельный загрузчик.

## Быстрый запуск через Docker

Нужны Docker Desktop и запущенный локальный сервер LM Studio. В LM Studio должна быть загружена модель `text-embedding-nomic-embed-text-v1.5`, а сервер должен слушать порт 1234.

Для агентных ролей используется `qwen/qwen3.5-4b`. Модель можно скачать и загрузить командами ниже.

```bash
lms get qwen/qwen3.5-4b --gguf -y
lms load qwen/qwen3.5-4b --context-length 8192 --parallel 1 --yes
```

Модель эмбеддингов `Nomic Embed Text v1.5` нужно скачать через раздел поиска LM Studio и загрузить перед запуском.

```bash
docker compose up --build -d
docker compose ps
docker compose exec api /app/.venv/bin/shopping-agent check-models
curl http://localhost:8010/health
curl -X POST http://localhost:8010/demo/verify
docker compose exec api /app/.venv/bin/shopping-agent verify-agent
```

Команда `check-models` проверяет и Qwen, и модель эмбеддингов настоящими запросами. Команда `verify-agent` запускает планировщик, исследователя и критика на задаче первого переезда.

Если порт 8010 занят, перед запуском задайте другой через переменную `API_PORT`.

Остановить сервисы можно так.

```bash
docker compose down
```

## Запуск без Docker

Qdrant всё равно должен быть доступен на порту 6333.

```bash
python -m venv .venv
python -m pip install uv==0.12.10
python -m uv sync --frozen --extra dev
python -m uv run uvicorn shopping_agent.api:app --reload
```

Для проверки тестов выполните команду.

```bash
python -m uv run --extra dev pytest
python -m uv run --extra dev ruff check src tests scripts
```

## Проверка агента через программный интерфейс

Готовый ответ возвращает запрос `POST /agent/run`. Поток промежуточных этапов возвращает `POST /agent/stream`.

Пример тела запроса

```json
{
  "message": "Собери набор для первого переезда в квартиру, бюджет 40000 рублей, готовлю часто, аллергия на шерсть"
}
```

Для продолжения диалога передайте полученный `session_id` вместе с новым сообщением.

```json
{
  "message": "Замени блендер на более мощный",
  "session_id": "session из предыдущего ответа"
}
```

Состояние можно получить через `GET /agent/sessions/{session_id}`. Трасса запуска доступна через `GET /agent/traces/{trace_id}`.

## Трассировка

Локальная трасса сохраняется всегда. Она содержит переходы графа, вызовы инструментов, длительность, использование модели и замечания критика.

Для отправки тех же запусков в Langfuse укажите `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY` и `LANGFUSE_HOST`. Без ключей приложение продолжит сохранять локальные трассы и не будет обращаться к внешнему сервису.

Langfuse можно полностью запустить локально без регистрации.

```bash
docker compose -f compose.yaml -f compose.langfuse.yaml up --build -d
```

После запуска интерфейс доступен по адресу `http://localhost:3000`. Учётная запись для локальной проверки использует адрес `admin@example.local` и пароль `shopping-agent-local`. Эти значения предназначены только для разработки на своём компьютере.

Обычная команда `docker compose up --build -d` не запускает дополнительные сервисы Langfuse.

Первый запуск Langfuse скачивает несколько образов и требует заметно больше памяти, чем обычный запуск. Остановить полный состав можно следующей командой.

```bash
docker compose -f compose.yaml -f compose.langfuse.yaml down
```

## Скорость локальной модели

На текущем компьютере первый уникальный запрос с Qwen на процессоре занял около 73 секунд. Повторный полный запрос с кэшем занял 24,9 секунды. Эти значения сохраняются в поле `metrics.duration_seconds` и будут использоваться при дальнейшей оптимизации.

## Настоящие данные Amazon

Файлы Amazon Reviews 2023 очень большие. Метаданные Home and Kitchen занимают около 3 ГБ в сжатом виде, а отзывы около 8 ГБ. Поэтому они не загружаются при обычном запуске.

Загрузчик читает локальные файлы `jsonl` или `jsonl.gz` потоково и может остановиться после заданного числа записей.

```bash
python scripts/import_amazon_reviews.py \
  --metadata data/raw/meta_Home_and_Kitchen.jsonl.gz \
  --reviews data/raw/Home_and_Kitchen.jsonl.gz \
  --limit-products 10000 \
  --limit-reviews 50000
```

После загрузки перезапустите приложение. Индекс обновится автоматически.

## Состояние реализации

Первый этап: проходят модульные тесты, Qdrant отвечает, LM Studio создаёт векторы, демонстрационная проверка возвращает товары из каталога и итоговая сумма совпадает с суммой позиций.

Второй этап: Qwen создаёт структурированный план, исследователь собирает корзину, критик подтверждает ограничения, сессия позволяет заменить один товар, а трасса сохраняет ход выполнения.

На третьем этапе появятся измерения на ESCI, сравнение вариантов поиска, проверки полных сценариев и простой пользовательский интерфейс.
