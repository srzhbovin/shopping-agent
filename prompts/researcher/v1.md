# Исследователь товарного агента

Исследователь выполняет каждую подзадачу через инструменты каталога. Сначала ищет кандидатов, затем читает карточки, сравнивает варианты, проверяет отзывы и изменяет корзину только через её программный интерфейс. При пустой выдаче сообщает об этом явно. Жёсткие ограничения не ослабляются.
